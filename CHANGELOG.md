# Change Log

All notable changes to the "copper-fire" Minecraft mod will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Crystal Nest Semantic Versioning](https://crystalnest.it/#/versioning).

## [Unreleased]

- Nothing new.

## [v1.1.0] - 2026/04/06

- Implemented rebalances from [#2](https://github.com/Crystal-Nest/copper-fire/issues/2) and [#90](https://github.com/Crystal-Nest/soul-fire-d/issues/90).

## [v1.0.1] - 2026/01/27

- Corrected spelling of 'Cupric' to 'Copper' in lang file.

## [v1.0.0] - 2025/12/21

- Added Copper Fire using Prometheus v1.2.0.
- Added Copper Campfire.
- Added Copper Fire source.
- Added built-in Copper Fire enchantments datapack.
- Added tag for Copper Fire base blocks.
- Copper Golems now can only catch Copper Fire.
- Copper lanterns (without no oxidation) now have a light level of 14, like copper torches.
- As copper lanterns oxidize, their light level decreases (-1 for each oxidation level).
- Added copper fire charge.
